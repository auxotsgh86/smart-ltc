# smart-ltc 設計決定（2026-11-19）

## 定位
- 使用單位：社區健保特約藥局
- 目的：長期追蹤會員健康指數（血壓、血糖、體重體脂、骨密度），提高回店率
- **客群特性：許多鄉親不識字，但大多看得懂阿拉伯數字**

## 已確定
1. **店內量測拿來集點，居家量測拿來追蹤**
   - 集點只計店內量測 → 客人仍需回店，順便消費
   - 客人在家量的數據透過 LINE 回報，畫進趨勢圖，標示「在家量」
   - 藥師可比較居家平均與店內數值（白袍效應），提供更專業的解說
2. **量測頻率依項目、依會員設定**（建議預設，可依醫囑調整）
   - 血壓：居家 722 原則（連續 7 天、早晚各一回、每回量 2 次取平均）；穩定後可每週數天
   - 血糖：依治療方式與醫囑，每位會員個別設定
   - 體重體脂：每 2–3 天一次
   - 骨密度：每 3–6 個月一次（變化以月、年計，量太密只會看到機器誤差）
3. **獎勵綁「完成量測」，不綁領慢箋**；禮品：面紙、益生菌、保養品試用組
   - 每月店內門檻（暫定）：血壓 8 次、血糖 4 次、體重體脂 4 次；同一天同一項只計 1 次
   - 連續 3 個月達標可選保養品試用組
   - 不送藥品；益生菌宣傳不寫療效
4. **資料存在藥局，但做去識別化**：只存會員編號，不存身分證字號；姓名電話加密存放
5. **病人手機拿到副本**：每次量完用 LINE／QR Code 傳報表，不用接線
6. **藥師預設為電腦小白**：一條引導式流程（報到 → 逐步量測 → 燈號解說 → 傳報表 → 下一位），按鈕大、少打字，量測儀器優先藍牙自動帶入
7. **技術**：Node.js + SQLite（Litestream 備份）+ React 網頁 + LINE，單一雲端主機（台灣機房）
8. **客人手機介面做在 LINE 裡（LIFF），不另做 App；設計為「不用識字」**
   - 只用圖片、顏色、表情、大數字和語音；文字只當小字說明（給家人、藥師看）
   - 4 個分頁（圖示）：記錄、變化、禮物、會員碼
   - 記錄：點儀器圖片 → 太陽／月亮選早晚 → 「拍照」（AI 讀數字）或「按數字」（大鍵盤，儀器圖上亮出要抄的那一格）→ 綠勾／紅叉確認
   - 血壓引導量 2 遍：中間 1 分鐘圓圈倒數，自動取平均
   - 結果：笑臉／平臉／哭臉 + 大數字 + 自動語音說明（正式版用藥師錄的台語語音）
   - 客人不能修改歷史資料（要改找藥師）；手機上不顯示完整個資
   - 一支 LINE 預設只顯示一個人；只有綁定多位家人的家屬帳號才出現「幫誰記錄」
   - 身分辨識靠 LINE 綁定，不靠手機號碼（LINE 與網頁都讀不到本機門號）
   - 家屬代填：子女或配偶的 LINE 可綁定、代為回報與查看，數值偏高時家屬也收到通知；需本人同意
9. **居家回報的路線優先順序**（因應不識字）
   1. 藍牙血壓計自動上傳（客人零操作；藥局可借用或販售）
   2. 拍照，由 AI 讀數字，客人只要按綠勾確認
   3. 家人代填
   4. 紙本記錄卡（圖示標早晚格，客人只寫數字），來店時藥師拍照匯入
10. **對外交換用 FHIR（TW Core IG），內部仍用 SQLite**；代碼對照表第一階段就建，輸出功能放第四階段

## 待確認
- 健保卡用於會員建檔：先問健保署分區業務組
- 獎勵設計：上線前問藥師公會或衛生局
- 健康資料同意書內容（含居家回報、照片保存、家屬代填、對外輸出）
- 不識字者的同意方式：藥師口頭說明、按指印或蓋章、見證人簽名——請律師確認
- 台語語音：由藥師錄音，或評估台語語音合成
